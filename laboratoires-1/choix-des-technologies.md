# Choix des technologies

## Intention

Ce laboratoire a pour intention de mettre en place votre environnement de développement afin de rapidement débuter une première implémentation.

Il s'agit également de réactiver certaines compétences comme l'UML, les API, la gestion des variables, les pratiques de code tels que les conventional commit et les différents git flow disponibles.

## Backlog

### Choix d'un framework

Vous êtes libres dans le choix du langage et du framework que vous désirez utiliser pour le module. Prenez bien garde à valider les informations suivantes:

* [ ] Framework adapté pour la réalisation d'API (en vue de faire des micro-services)
* [ ] Librairies de test offrant:
  * [ ] des objets de test (mocks, stubs)
  * [ ] méthode permettant de factoriser les tests (setup all, tear down, before each/all)
* [ ] Gestion "facilité" injection de dépendances
* [ ] Les bonnes pratiques du langage doivent être appliquées (convention de nommage entre autres)
* [ ] Le standard du langage doit être suivi (PSR, PEP8, ECMA)
